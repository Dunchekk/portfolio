# Jetset: наблюдения и принятые решения

Проверено 2026-11-11 в браузере: https://www.jetset.nl/, /preview,
/archive/statement-and-counter-statement-2, /about. Изучены DOM и CSS exj.css.

- Белый фон; Helvetica/Arial около 13.25px, line-height 1.4.
- Контейнер 1088px на экране 1280px, до 1700px на широком экране.
- Название сверху слева, Search справа, вертикальное меню; нижняя граница шапки.
- Archive — текстовый каталог: название + месяц/год; CSS columns шириной 16em,
  gap 2em. Сортировка alphabetical/chronological, категории, поиск.
- Неописанные проекты показаны зачеркнутым текстом, без ссылки.
- Preview — отдельный список миниатюр; проект /archive/[slug]; prev/next.
- Нет единого обязательного layout проектов: проверенный новый проект использует
  обычные параграфы и изображения в потоке. About применяет CSS columns 25em/gap 2em.
- На странице видны пути Joomla/JCE и CSS для TinyMCE; это свидетельство
  используемых инструментов, но устройство закрытой CMS и хранения не проверено.

Реализация portfolio повторяет язык интерфейса, каталог, preview, категории,
поиск, сортировку, About, Contact, News и переходы между проектами. По явному
требованию пользователя страницы проектов имеют 3 управляемые колонки,
на мобильном экране — одну. Не копируем чужие проекты/фотографии/название.

Админка хранит упорядоченные типизированные блоки, а не HTML. Пустая строка
разделяет абзацы; перенос внутри абзаца сохраняется. Фото масштабируются по ширине
с сохранением пропорций. Каталожный анонс (LISTED) отличается от закрытого DRAFT
и полноценной страницы PUBLISHED. Обновление опубликованного проекта сразу
меняет публичный материал; отдельного редакционного слоя ревизий пока нет.

Дополнительно проверен /archive/whitney-museum-identity: в DOM — p, strong/b,
i/em, a, br, blockquote, img. Редактор поддерживает жирный/курсив, ссылки,
цитаты, списки, переносы и абзацы. Списки — небольшое удобство нашего редактора;
наличие этого блока в проверенной статье Jetset не подтверждено.
